# O*NET
* occupations are too granular - we want to be concerned with college majors

# Open-Psychometrics
* the only problem with this dataset is that it's college major only
    * so there would be limitations in recommendations outside of college education
* from 2018, still revelant imo
* ~57k undergrad + postgrad
* ~80k if you include max high school-educated (but this doesn't make sense because the next question asks "if you went to university, what was your major?")
